## 3. 已完成功能

### 3.1 Asset Registry

- 资产创建、列表、详情、更新、软删除。
- `asset_id` 自动生成。
- 支持业务线、类型、负责人、状态、标签、可见范围。
- 文件上传到 `01_raw/`。
- 文件 checksum、大小、类型、上传人记录。
- 资产状态、版本、来源、创建人、更新人记录。

### 3.2 解析 Worker

- 支持 Markdown、TXT、CSV。
- 支持 PDF。
- 支持 DOCX。
- 支持 XLSX。
- 解析后生成 Markdown。
- 切分 Chunk。
- 写入 ProcessingJob。
- 记录成功、失败、错误原因。
- 解析产物写入 `02_staging/`。

### 3.3 审核中心

- 待审核队列。
- 审核通过。
- 驳回。
- 归档。
- 审核记录。
- 状态机校验。
- 只有 Approved 资产可以继续索引。

### 3.4 索引与检索

- Approved 资产才能索引。
- 索引后可进入 Serving。
- Chunk 生成与存储。
- Search API。
- 状态过滤。
- 业务线过滤。
- 资产类型过滤。
- 权限过滤。
- 相关度评分。

### 3.5 问答

- Ask API。
- 只使用 Approved / Indexed / Serving 资产。
- 返回 answer。
- 返回 citations。
- 返回 asset_id、标题、片段、版本、更新时间。
- 支持 DeepSeek 可选接入；未配置 API Key 时返回检索式答案。

### 3.6 Agent

- `search_assets()`。
- `read_asset()`。
- `generate_report()`。
- 权限过滤。
- 状态过滤。
- Agent 日志。
- 控制台可视化执行。

### 3.7 知识图谱

- Entity 表。
- Relationship 表。
- 来源资产追溯。
- Graph API。
- 图谱视图。
- 初始化演示图谱。

### 3.8 BI 与治理

- BI Metrics API。
- 资产状态分布。
- 任务成功率。
- 审核数量。
- 切片总数。
- 被调用次数。
- Agent 调用数。
- 审计日志。
- 用户角色视图。

### 3.9 部署骨架

- Dockerfile。
- Docker Compose 生产配置。
- PostgreSQL。
- Nginx。
- 环境变量模板。
- 存储目录结构。
- 健康检查。

## 5. 手工验收路径

打开：

```text
http://127.0.0.1:13001/
```

验收顺序：

```text
1. 总览查看资产总数、处理中、待审核、已通过、服务中、失败任务。
2. 进入资产中心，查看 20 个资产。
3. 进入处理中心，查看任务状态。
4. 进入审核中心，处理待审核资产。
5. 进入知识检索，提问：妆舟渠道分销怎么处理订单？
6. 检查答案是否带 asset_id、标题、片段、版本和更新时间。
7. 进入 Agent 助手，执行 search_assets。
8. 进入知识图谱，查看实体和关系。
9. 进入系统设置，查看服务状态、指标和用户。
```

## 7. 当前边界

以下能力属于“验收可用”，还不是大型企业生产级最终形态：

```text
解析 Worker 内嵌在 Core API 中，尚未拆成独立队列服务。
索引当前是内置关键词 / 相关性索引，RAGFlow / pgvector 可作为下一层替换。
Ask API 已支持 DeepSeek 可选接入；未配置 Key 时返回检索式答案。
权限模型已覆盖角色、业务线和可见范围，但字段级权限未实现。
企业数据源连接器尚未全部接入。
知识图谱当前支持关系录入和展示，AI 自动抽取和图数据库尚未接入。
```

# 008 Feature：妆舟业务数据中台深化

## 背景

第 1-6 期验收版已经具备资产、文件、解析、审核、索引、检索、问答、Agent、图谱、BI 和审计能力。  
本轮继续把系统升级为真实可运营的妆舟业务数据中台。

## 已完成

### 1. 资产生命周期历史

新增：

- `asset_events`：资产事件表
- `processing_runs`：处理运行历史表
- `assets.business_domain`
- `assets.business_entity`
- `assets.business_metrics`
- `assets.lifecycle_bucket`

每个资产可返回完整 timeline，包含：

- 登记事件
- 解析 / 清洗事件
- 审核事件
- 索引事件
- 服务事件
- 任务记录
- 修改审计
- 状态变化

### 2. 数据目录生命周期接口

新增：

```http
GET /api/v1/catalog/lifecycle
GET /api/v1/assets/{asset_id}/timeline
GET /api/v1/assets/{asset_id}/events
POST /api/v1/assets/{asset_id}/events
```

生命周期分区包括：

```text
raw / parsed / cleaned / waiting_review / approved / indexed / serving / failed / archived
```
